# Changelog

What changed in each release of Clair. Generated by [Changie](https://changie.dev) from `.changes/`; edit those files, not this one.

## 0.1.2 - 2026-11-05

- Changed: The disk image opens to a styled window: Clair and Applications side by side, with an arrow showing where to drag Clair, and Clair's icon on the mounted disk

## 0.1.1 - 2026-11-05

- Changed: This release tests Clair's automatic updates. Nothing else changes

## 0.1.0 - 2026-11-05

- New: First release of Clair, a macOS browser built on ungoogled-chromium, with automatic updates
- Updated: Update the engine to Chromium 156.0.8078.79 (ungoogled-chromium 156.0.8078.79-1)
- Changed: macOS's local network permission prompt now explains why Clair asks for access
- Fixed: Clair no longer looks in Chromium's or Google Chrome's folders for preferences, extensions, native messaging hosts or other settings, and web app shortcuts now go in a Clair Apps folder
- Changed: The first run page now names Clair and its Dictionaries folder, and the About page reads "Official Build"
- New: About Clair opens Clair's own About window, with the Clair version, the Chromium engine version and the open source credits
- Fixed: Settings, Safety Hub and the certificate manager now show Clair's ring instead of Chromium's logo
